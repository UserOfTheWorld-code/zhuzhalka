# Проверка Жужалки 0.3.0-alpha.3

Версия `0.3.0-alpha.3`, код `5000302`. Добавлена передача установленного приложения
через QR-код, ссылку и системное меню отправки Android. APK alpha.3 в GitHub пока
не опубликованы. Полная локальная сборка debug и подписанных release APK завершена.
Статическая проверка всех 20 APK и перечисленные Android-сценарии завершены.
Результаты относятся к одному эмулятору; ограничения вынесены в Not run.
Исторический [отчёт alpha.2](version-0.3-alpha.2-validation.md) не заменяет проверку нового APK.

## Что изменено

- Кнопка «Поделиться Жужалкой» внизу главного экрана открывает `ShareAppActivity`.
  QR-код и действие отправки ссылки используют только
  `https://github.com/UserOfTheWorld-code/zhuzhalka/releases`. Для скачивания по QR
  требуется интернет; ссылка не обещает конкретную версию. Текущий публичный выпуск —
  `v0.1.0-beta.1`; alpha.3 можно передать как установленный APK.
- «Передать APK» копирует установленный файл и открывает Android Sharesheet.
  Bluetooth и Quick Share (Wi-Fi) доступны только если их предлагает Android на
  конкретном устройстве. Собственный транспорт и подтверждение доставки не реализованы.
- Копируется приложение, без чтения и добавления личных подписок, профилей, настроек
  или ключей сообщества. Передаваемые версия, пакет и архитектура соответствуют
  установленному APK. При несовместимости получателю нужен universal APK;
  split-установка отклоняется с предложением передать ссылку.
- Копирование выполняется вне главного потока, поддерживает отмену и удаление
  незавершённой копии. Готовые файлы помещаются в `cache/shared-apks/`; собственные
  копии старше 48 часов убираются при следующей подготовке. Android может очистить
  кеш раньше, а очистка не является фоновым таймером с гарантированным сроком.
- Отдельный FileProvider `${applicationId}.share` ограничен каталогом копий APK.
  Получателю выдаётся временный URI-доступ только на чтение под управлением Android;
  немедленный отзыв при закрытии меню не гарантируется. Новых разрешений Android нет.
- Все 15 новых строк добавлены во все 10 поддерживаемых локалей; прежние строки
  сохранены. Версии приложения, workflow, упаковки и публикации согласованы;
  выпуск остаётся prerelease и не назначается стабильной `latest`.

Механизм передачи соответствует стандартному
[Android Sharesheet](https://developer.android.com/training/sharing/send).
Требования и действия получателя Quick Share описаны в
[справке Android](https://support.google.com/android/answer/9286773).
QR Жужалки ведёт на GitHub, а не запускает собственную передачу Quick Share.

## Not run

- Передача по Bluetooth или Quick Share между физическими телефонами, камера другого
  телефона и установка полученного APK на нём — требуются реальные устройства.
- Физические ARM-устройства и старые Android API — текущая среда проверки является
  эмулятором API 35 / `x86_64`.
- Полный TalkBack и озвучивание — не проверялись. Клавиатура и D-pad проверены только
  для перечисленных выше действий.
- Реальная split-установка, отмена во время копирования APK на Android, принудительное
  отсутствие обработчика отправки и удаление
  Android кеша во время внешнего чтения — пока нет результатов платформенных сценариев;
  unit-проверки не заменяют их.
- Повторная проверка сетевых функций сообщества, VPN-туннеля, сообщений и звонков —
  не входит в изменение передачи приложения; результаты прежних версий остаются отдельными.
- Удалённый GitHub Actions и публикация APK alpha.3 — не выполнялись.
