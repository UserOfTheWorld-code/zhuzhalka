# Проверка Жужалки 0.3.0-alpha.2

Версия `0.3.0-alpha.2`, код `5000301`. Обновлено оформление: чёрный фон,
нейтральные поверхности, жёлтый акцент `#FFD43B` и сохранённая пчела.
Подписанные APK собраны и проверены локально; APK alpha.2 в GitHub ещё не опубликованы.
Проверки [alpha.1](version-0.3-alpha.1-validation.md) остаются историческими
и не заменяют проверку нового APK.

## Подготовка

- Проверены прямые цвета в основном экране, обновлениях, настройках и расширенном
  списке серверов. Экран обновлений и настройки используют MaterialTheme; отдельные
  цвета ping, типа профиля, кнопки VPN и уведомлений входят в общую палитру.
- Кнопка VPN в расширенном режиме использует контрастный `onPrimary` в обоих состояниях.
  Пчела в боковом меню больше не перекрашивается целиком белым.
- Рамка QR-сканера использует общий жёлтый акцент; код камеры и разрешений не менялся.
- Страница лицензий получила чёрный фон и жёлтые ссылки через CSS. Всё содержимое
  после `</style>`, включая тексты лицензий и якоря, точно совпадает с предыдущим коммитом.
- Версии упаковщика, публикации, workflow и инструкций согласованы с alpha.2.
  Выпуск остаётся prerelease; автоматическое повышение до latest не предусмотрено.

При первом прогоне обнаружены перенос букв заголовка и исчезновение поля подписки
из доступной области IME; они исправлены и повторно проверены. Доказательства находятся
в `.toolchain/ui-alpha2-20261030/`: `final-main-large-narrow.png`,
`final-subscription-ime-input.png`, `final-subscription-confirm-focus.png`,
`final-invalid-validation.png`, `fdroid-before-upgrade.json`, `fdroid-after-upgrade.json`
и `final-signed-fdroid-disabled-persisted.xml`. Публичные скриншоты выше показывают
обычный размер шрифта. В системном журнале отмечался ANR `com.google.android.as`;
это отдельный системный процесс, при перечисленных действиях приложение отвечало.
Итоговая сводка — `runtime-summary.json` в той же папке. Исходные системные настройки
возвращены, VPN выключен в обеих установках; тестовый эмулятор и его ADB остановлены.

**Not run:** полный проход D-pad/TalkBack, восстановление введённого URL при пересоздании
диалога, полный проход расширенных настроек, QR-сканирование камерой и активная кнопка
VPN в работающем расширенном режиме. Последняя проверена по цветам в коде, без запуска службы.

**Not run:** физические ARM-устройства, старые Android API, обновление именно с 0.2,
запуск Playstore release APK, удалённый GitHub Actions и публикация APK alpha.2.

**Not run:** повторная проверка сетевых функций сообщества, VPN-туннеля, сообщений
и звонков в этой версии оформления. Результаты alpha.1 остаются отдельными.
