## Границы результата

Три веб-проверки выполняются через отдельный профиль Xray. Они не подтверждают работу
всех приложений через системный VPN, сообщений или звонков. Запущенная VPN-служба также
не является доказательством успешного интернет-трафика через туннель.

Обновляющий компонент обращается к GitHub напрямую; включённый VPN не устраняет ограничения
его прямого сетевого доступа. APK из локальной и облачной сборок проверяются отдельно,
даже если они собраны из одного коммита и подписаны одинаковым сертификатом.
