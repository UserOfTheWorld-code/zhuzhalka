# Проверка Жужалки 0.3.0-alpha.4

Версия `0.3.0-alpha.4`, код `5000303`. Отчёт от 31 октября 2026 года фиксирует
локальные проверки перед упаковкой. Финальный коммит указан тегом выпуска и
`BUILD_INFO.json` в архиве исходников; статус публикации и побайтовая проверка
опубликованных файлов — в запуске GitHub Actions, ссылка на который приведена
в описании выпуска. Целевые тесты, полная локальная сборка, статическая
проверка 20 APK и перечисленные ниже Android-сценарии завершены.
В пределах выполненных проверок блокирующих ошибок приложения не обнаружено;
остальные сценарии явно перечислены в `Not run`.

Результаты [alpha.3](version-0.3-alpha.3-validation.md) и более ранних версий
остаются отдельными историческими проверками и не подтверждают новый APK.
Указанные ниже `.toolchain/…` — локальные доказательства в рабочем каталоге вне
репозитория, а не файлы, включённые в архив исходников.

## Что изменено

- Главный экран сохраняет пчелу, чёрный фон и единственный жёлтый акцент;
  дополнительные действия сгруппированы, а публикация списка предлагается
  отдельным выключенным по умолчанию выбором при добавлении подписки.
- Автоподбор больше не отвергает профиль только из-за `insecure=true`.
  Для проверки создаётся отдельный снимок с `insecure=false`, сохраняющий SNI,
  pin и параметры REALITY. Используется именно этот снимок, без повторного
  чтения изменившегося профиля и без неявной цепочки прокси. Исходный профиль
  меняется только после успешных проверок всех трёх HTTPS-адресов и повторной
  проверки его идентичности; ошибка, отмена или изменение профиля не должны
  сохранять результат для другого подключения.
- Это не единая проверка сертификатов для всех протоколов: pin сохраняет
  исходную модель доверия, REALITY использует собственную аутентификацию,
  а Shadowsocks и WireGuard не становятся TLS-соединениями. Получение
  сертификата без проверки доверия не используется как доказательство безопасности.
- Списки для автоподбора загружаются напрямую, без попытки использовать
  остановленный локальный прокси. Загрузка поддерживает отмену, общий срок
  до 15 секунд либо оставшийся бюджет поиска, HTTPS-перенаправления в пределах
  того же срока и ограничение распакованного ответа 8 MiB. Неудачная загрузка
  нового списка не должна оставлять пустую группу. Обычное ручное обновление
  подписки остаётся отдельным путём.
- Явное согласие на общий список привязано к группе и точному URL. Публикуемый
  URL, включая возможный токен, становится доступен читателям и операторам relay.
  Принятие чужого списка разрешает последующее обновление во время автоподбора
  и обмен оценками при включённом участии, но не повторную публикацию URL.
- Разрешение на публикацию хранится между запусками. Следующие обмены обновляют
  объявление, но не время старых проверок серверов. Изменение URL, удаление или
  отключение подписки, приватные заголовки и пользовательский User-Agent
  отзывают разрешение. Старый формат читается без превращения прежнего
  одночасового объявления в постоянное согласие. Новый протокол публикует v2
  и читает v1/v2; старые клиенты v1 не получают новые объявления v2.
- Сохраняются QR-код страницы релизов, передача установленного APK через
  Android Sharesheet и проверка обновлений приложения. Это не собственный
  Bluetooth/Wi-Fi транспорт и не подтверждение доставки другому телефону.

Эти пункты описывают реализацию. Статусы её проверок приведены ниже.
Native-зависимости не обновлялись: gitlink AndroidLibXrayLite остаётся
`76a6e2172210613fcb4aa32b6de55bcd9452ce43`.

## Not run и границы результата

- Две независимые установки alpha.4: фактический приём и продление предложений v2
  через relay, а также удалённое получение отзыва — остановлены по согласованному
  ограничению времени QA. Локальный readback и unit-тесты не заменяют эту проверку.
- Отдельное пересоздание при смене ориентации и активация checkbox клавиатурой/D-pad —
  не проверены. Tab в многострочном поле URL вставил пробел, а не перевёл фокус;
  обычный импорт удалил завершающий пробельный символ, сохранённый URL совпал с подтверждённым.
- Полный UI-автоподбор и запись строгого результата после трёх успехов — не проверены
  на Android в этом прогоне. Их детерминированная логика покрыта прошедшими unit-тестами;
  native-аудит отдельно проверяет реальное подключение без сохранения профилей.
- Физические ARM-телефоны и все поддерживаемые версии Android — среда ограничена
  доступным эмулятором; сборка ABI не заменяет запуск на соответствующем устройстве.
- Передача APK по Bluetooth/Quick Share между физическими телефонами и установка
  на получателе — требуются реальные устройства. Возврат из Sharesheet не означает доставку.
- Полная проверка TalkBack с озвучиванием — результата для alpha.4 пока нет.
- Работа самих приложений WhatsApp, Telegram и X: вход, сообщения, звонки, UDP,
  скорость и приватность — HTTPS-проверки подтверждают только доступ к выбранным адресам.
- Обмен между всеми установленными копиями, постоянная фоновая доставка и доступность
  внешних relay — не гарантируются. Подпись не доказывает независимость разных пользователей.
- Измеренное ускорение alpha.4 — сравнительного результата ещё нет. Общий бюджет
  автоподбора остаётся 180 секунд; уже начатый native-вызов может закончиться позже
  дедлайна или запроса отмены. Изменение HTTP-загрузки не делает native-вызовы отменяемыми.
- GitHub Actions, публикация alpha.4 и повторное скачивание её публичных файлов —
  отдельный этап после фиксации этого отчёта. Его результат указан в описании
  выпуска; публикация иной версии не подтверждает готовность alpha.4.
