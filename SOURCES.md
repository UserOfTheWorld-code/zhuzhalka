Зависимости Go и их ревизии закреплены в `AndroidLibXrayLite/go.mod` и `go.sum`;
зависимости Android — в `V2rayNG/gradle/libs.versions.toml`. Лицензии вложенных компонентов
сохраняются в их каталогах. Указанные ревизии описывают исходники, а не подтверждают
соответствие произвольного скачанного бинарного файла. Для каждой поставляемой APK следует
сохранить данные сборки и фактическое происхождение native-библиотек.

Изменения этой сборки: отдельный идентификатор `app.zhuzhalka.vpn`, название «Жужалка»,
векторная иконка пчелы, интерфейс для бесплатных источников и собственных подписок.
Рисунок пчелы создан непосредственно в XML-векторе без внешнего графического материала.
Исходный README и тексты лицензий не заменяются новым названием приложения.

## Серверы существующих бесплатных VPN: VPNBook

Официальный источник: <https://www.vpnbook.com/freevpn/outline-vpn>.
Страница выдаёт публичные ключи для личного использования без регистрации; это публикация
самого VPN-провайдера, а не найденные в стороннем приложении приватные данные.
VPNBook указывает смену ключей каждые 1–2 недели; на проверенной странице последняя смена
датирована **24 октября 2026**.

Проверенный HTTPS-ответ: **200**, `text/html; charset=utf-8`, **194 942 байта**,
HTTP Date **2026-10-30 13:16:19 UTC**. В Next.js-данных страницы найдены три `ss://` URI.
Все используют `chacha20-ietf-poly1305` и порт `443`; поле пароля присутствует и корректно
декодируется. Сами ключи не включены в этот документ.

| Официальный адрес | DNS-адрес на момент проверки | Сравнение с Au1rxx и Eternity |
|---|---|---|
| `pl134.vpnbook.com:443` | `54.36.174.134` | Полный профиль Shadowsocks уже есть в обоих каталогах |
| `pl140.vpnbook.com:443` | `54.36.174.140` | Полный профиль Shadowsocks уже есть в обоих каталогах |
| `ca225.vpnbook.com:443` | `142.4.216.225` | Не найден по имени, IP или полной конфигурации |

Для этой проверки сравнивались протокол, нормализованное имя, порт, шифр и декодированный ключ.
Название сервера и параметр `outline=1` не меняют подключение. DNS-разрешение выполнялось
только для поиска IP-алиасов; соединение через VPN не устанавливалось. После устранения
совпадений этот снимок даёт **один новый сервер**, а не три. Число может меняться при обновлениях.

Ключи находятся в экранированной JSON-строке HTML. Адаптер должен извлекать URI только
с этого официального HTTPS-адреса, завершать URI перед обратной косой чертой/кавычкой,
проверять формат и затем использовать обычный импорт профиля. HTML-страница не является
обычной Base64-подпиской. При изменении разметки необходимо сообщить об ошибке обновления,
сохранив прежние профили.

[Условия и политика VPNBook](https://www.vpnbook.com/contact): сервис предназначен для
личного использования; для коммерческого применения предлагается отдельно связаться с
провайдером. Он сообщает, что сохраняет IP и время соединения и удаляет журналы еженедельно.
Поэтому приложение не должно называть этот источник сервисом без журналирования.

Другие проверенные варианты:

- [VPN Gate](https://www.vpngate.net/en/) официально разрешает использовать CSV-каталог
  для собственных клиентов, но публикует OpenVPN/SoftEther/L2TP/SSTP, не поддерживаемые
  текущим Xray-клиентом. Одного IP недостаточно, чтобы превратить такой сервер в VLESS/SS.
- [VPNBook WireGuard](https://www.vpnbook.com/freevpn/wireguard-vpn) выдаёт отдельную конфигурацию
  на одно устройство сроком на 7 дней после подтверждения условий. Общие WireGuard-ключи
  для встраивания в APK не опубликованы; генерация персональных конфигураций не выполнялась.
- [Proton VPN](https://protonvpn.com/support/android-vpn-setup) предоставляет ручные конфигурации
  через аккаунт. Гостевой режим официального приложения не является общей публичной подпиской
  для произвольного клиента; чужие аккаунты и ключи не использовались.
- [MegaV Public](https://github.com/Romaxa55/MegaV_Public) содержит бесплатные community-конфигурации,
  но публикатор прямо отмечает, что эти сторонние серверы ему не принадлежат. Не включён как
  отдельный источник собственных серверов другого VPN-провайдера.

## Границы проверки

Каталоги намеренно публикуются как бесплатные публичные источники. Независимая проверка
происхождения каждого узла и согласия его владельца не выполнялась; наличие открытого файла
само по себе этого не доказывает. Лицензия агрегатора не устанавливает доверие к операторам узлов.

Не проверялись соединение с узлами, доступность из России, скорость, отсутствие журналирования,
лимиты, передача UDP и работоспособность конкретных приложений. Удаление каталога или узла
находится вне контроля клиента. Внешние подписки пользователя могут иметь собственную плату,
срок действия и ограничения и не должны попадать в исходники, журналы или общий архив.
